# 胶凝剂体系速查

## 吉利丁（Gélatine）

| 参数 | 标准值 |
|------|------|
| 力度 | 200 Bloom（法式专业厨房标准） |
| 泡发 | 冷水（5-10倍重量），5–10 分钟 |
| 溶化温度 | ≥ 50°C 加入热液体，或隔水融化 |
| 失活温度 | 长时间 > 80°C 会破坏胶力 |
| 有效 pH | 4–10 |
| 冷藏凝固 | 4°C / 2–4 小时 |
| 热可逆 | 是（约 30°C 以上开始融化） |

**粉状吉利丁**：直接撒入冷水，比例同上，用量与片状等换算：1g 粉 ≈ 1g 片。

## 果胶 NH（Pectine NH）

| 参数 | 标准值 |
|------|------|
| 来源 | 苹果或柑橘皮 |
| 用量 | 0.8–1.5%（占配方总重） |
| 溶化方式 | 与砂糖混合后加入热液体（≥ 85°C），避免结块 |
| 有效 pH | 2.5–6.5 |
| 热可逆 | 弱（与吉利丁相比稳定性更高） |
| 适用场景 | 镜面果冻、夹心果冻层、高酸水果夹心 |

## 琼脂（Agar-agar）

| 参数 | 标准值 |
|------|------|
| 用量 | 0.5–1%（占总重） |
| 溶化温度 | ≥ 85°C |
| 凝固温度 | 35–45°C（室温即可凝固，比吉利丁快很多） |
| 有效 pH | > 2 |
| 热可逆 | 否（脆性凝胶，重新加热会融化但质地有变化） |
| 适用场景 | 热凝胶、球形化、展示件、素食替代 |

## 选择决策树

```
需要在冷藏中稳定？
├── 是 → 是否高酸（pH < 3.5）？
│   ├── 是 → 果胶 NH（或增量吉利丁）
│   └── 否 → 吉利丁（标准方案）
└── 否（室温展示）→ 琼脂 或 卡拉胶
```
