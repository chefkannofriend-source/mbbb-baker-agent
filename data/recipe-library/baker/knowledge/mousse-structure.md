# 慕斯结构稳定性

## 慕斯的三层结构

```
风味基底（Base）
    ↓ 提供味道和结构骨架
胶凝剂（Hydrocolloid）
    ↓ 提供网络支撑
充气体（Aeration）
    ↓ 提供轻盈感
= 稳定慕斯
```

## 胶凝剂用量标准

### 吉利丁（Gélatine）

| 用途 | 用量（占慕斯总重） | 效果 |
|------|----------------|------|
| 轻质/杯装 | 1–1.5% | 轻盈，不可脱模 |
| 标准慕斯蛋糕 | 1.8–2.2% | 可脱模，切面光滑 |
| 运输/展示级 | 2.5–3% | 坚实，耐温能力稍强 |

> 吉利丁力度标准：200 Bloom（法国LCB常用）。
> 若用 150 Bloom，同等效果需增加约 20% 用量。

### pH 影响

- 吉利丁有效工作范围：pH 4–10
- pH < 3.5（柠檬、百香果）：显著抑制凝胶，需多加 0.3–0.5g/100g 或改用果胶 NH
- 高酸慕斯可先中和基底（加奶油、糖）再加吉利丁

### 巧克力慕斯

巧克力本身含可可脂，可提供额外结构：
- 黑巧慕斯：吉利丁可减至 1–1.5%（可可脂补结构）
- 牛奶巧/白巧：仍需 1.8–2% 吉利丁

## 充气体（Aeration）标准

### 打发奶油

- 脂肪含量需 ≥ 35%（低脂奶油打发后结构弱）
- 打至**软峰（bec d'oiseau）**状态，不可过打
- 过打 → 脂肪球破裂 → 分离 → 慕斯出水、颗粒感
- 奶油温度：4–6°C 操作最稳定

### 蛋白霜（Meringue Italienne）

- 替代打发奶油的充气方案，更稳定、保质期更长
- 糖浆温度：117–121°C（软球阶段）
- 常见于酸度高的水果慕斯（不会因酸性破坏打发奶油）

### Pâte à bombe

- 蛋黄 + 热糖浆打发，用于巧克力慕斯基底
- 增加乳化能力，减少对吉利丁的依赖

## 组装温度控制

| 阶段 | 温度要求 |
|------|---------|
| 吉利丁溶化 | 加入 60°C 以上液体 |
| 基底冷却后加入奶油 | 基底温度 22–28°C |
| 组装完成后入急冻 | -18°C，最少 2 小时定型 |
| 脱模 | 外层用热毛巾或喷枪稍加热，立即脱模 |

> 基底过热（>35°C）加入打发奶油 → 奶油融化 → 失去充气 → 慕斯密实下沉

## 结构失败的常见原因

| 症状 | 原因 | 修复方向 |
|------|------|---------|
| 慕斯出水/塌陷 | 奶油过打或温度过高 | 控制奶油状态和基底温度 |
| 质地太硬/橡皮感 | 吉利丁过多 | 按总重计算，不按配方人数估算 |
| 切面气孔大 | 折叠手法过重 | 改用刮刀从底部翻折 |
| 吉利丁有颗粒 | 未完全溶化 | 先泡发，再隔水或微波融化后加入 |
| 高酸慕斯不凝固 | pH 抑制吉利丁 | 增量或改用果胶 NH |
