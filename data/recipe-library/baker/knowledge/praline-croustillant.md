# Praliné 帕林内

## 自制帕林内（50% Praliné）

**比例（坚果总量 = 100%）：**

| 原料 | 比例% |
|------|------|
| 坚果（榛子+杏仁各半） | 100% |
| 糖 | 100% |
| 水 | 40% |

→ 坚果:糖 = 1:1，最终成品中坚果占总重 **50%**（即"50% praliné"）

标准做法：糖+水熬至焦糖化 → 倒入烤热坚果 → 冷却后破碎研磨成酱

## Croustillant Praliné 帕林内脆底

脆底 = 帕林内 + 巧克力（粘合） + Feuilletine薄脆（酥脆感）

| 原料 | LCB常用比例% | 范围% |
|------|-----------|------|
| 帕林内 | 38–40% | 37–71% |
| 牛奶巧克力（融化） | 31–35% | 0–37% |
| Feuilletine薄脆 | 28–32% | 0–41% |
| 可可脂（调流动性） | 0–14% | 0–14% |

**最简版**（巧克力+帕林内+薄脆三等分）：

```
100g 帕林内 + 80g 牛奶巧克力 + 75g Feuilletine
```
→ 来源：`glm/intermediate/valencia.md`

## 帕林内在复合配方中的使用量

| 应用场景 | 帕林内占场景总量% |
|---------|-----------------|
| 慕斯林奶油（Paris-Brest） | 约15%（120g/800g总慕斯林） |
| 脆底配方 | 37–40% |
| 纯内馅（高帕林内夹心） | 最高71% |
