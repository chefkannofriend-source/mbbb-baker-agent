# Biscuit Joconde 达克瓦兹杏仁蛋糕体

## 标准比例（杏仁粉 = 100%）

| 原料 | 比例% | 备注 |
|------|------|------|
| 杏仁粉 | 100% | 基准（140g） |
| 糖粉 | 85.7% | — |
| 全蛋 | 142.9% | — |
| 低筋面粉 | 28.6% | — |
| 融化黄油 | 21.4% | — |
| 蛋清（单独打发） | 85.7% | — |
| 细砂糖（蛋清用） | 28.6% | 约为蛋清量的1/3 |

> **GLM库中三个Joconde配方核心结构完全一致**，高度标准化。

## 操作结构

```
① 全蛋 + 糖粉 + 杏仁粉 → 打发至蓬松
② 加入面粉，折入
③ 加入融化黄油，折入
④ 蛋清 + 细砂糖 → 打至中性发泡（湿性）
⑤ 将④轻折入③
⑥ 摊平烤盘，180°C烤8–10分钟
```

## 巧克力Joconde（Jamaica变体）

可可粉 28.6%，替换等量面粉：
- 面粉 40g → 保留
- 可可粉 40g → 新增（等量追加）

## Dacquoise 达克瓦兹蛋糕底

### 标准比例（蛋清 = 100%）

| 原料 | 标准版% | 椰子版% |
|------|--------|--------|
| 蛋清 | 100% | 100% |
| 细砂糖（打发用） | 71.4% | 76.9% |
| 杏仁粉（或榛子粉） | 71.4% | 46.2% |
| 糖粉 | 39.3% | 76.9% |
| 面粉 | 25% | 30.8% |
| 椰蓉（椰子版专用） | — | 30.8% |

### 变体说明

- **标准杏仁版**：r1配方
- **榛子版**：r2，将杏仁粉等量替换为榛子粉，结构相同
- **椰子版**（Dacquoise coco）：杏仁粉减半 + 椰蓉补充，糖粉比例大幅提升

### Dacquoise vs Joconde

| 对比维度 | Joconde | Dacquoise |
|---------|---------|-----------|
| 全蛋 | 是 | 否 |
| 黄油 | 是（21%） | 否 |
| 质地 | 较湿润有弹性 | 干爽酥松 |
| 主要用途 | 慕斯蛋糕围边、多层基底 | 塔底、慕斯蛋糕底 |
